# Arthur Ramalho Freire — Portfólio

Portfólio pessoal de Desenvolvedor Full Stack, em uma única página HTML com CSS e JS embutidos.

- Terminal interativo no hero (digite `help`)
- Tema claro/escuro, animações com respeito a `prefers-reduced-motion`
- Conteúdo centralizado no objeto `CV` dentro de `index.html`

Para rodar localmente, basta abrir o `index.html` ou servir a pasta:

```bash
npx http-server .
```
